# TARIK Icon Set Documentation

37+ official line icons for every module in the system, drawn in the TARIK hornbill’s green (`#1F5D3A`) and beak orange (`#D9622B`). 

## Icon Component Usage

```jsx
import { TarikVectorIcon } from '../components/TarikIcons';

<TarikVectorIcon name="dashboard" size={24} strokeWidth={1.75} />
```

## Available Icons
- `mascot`, `dashboard`, `students`, `teachers`, `users`, `curriculum`, `subjects`, `sections`, `enrollment`, `lessons`, `competency`, `classRecords`, `assignments`, `gradingScales`, `rankings`, `attendance`, `gateCheck`, `aral`, `immersion`, `career`, `certifications`, `submissions`, `compliance`, `interventions`, `guidance`, `conduct`, `rooms`, `announcements`, `notifications`, `consent`, `analytics`, `depedForms`, `ai`, `messages`, `mfa`, `audit`, `privacy`, `settings`.
