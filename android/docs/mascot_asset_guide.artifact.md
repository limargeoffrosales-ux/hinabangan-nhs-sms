# TARIK Mascot Asset & Resource Guide
**UGOP Platform — Hinabangan National High School, Samar (DepEd Region VIII)**

---

## 🦜 1. Mascot Identity & Anatomy
- **Mascot Name**: **TARIK** (Samar Tarictic Hornbill / *Penelopides samarensis*).
- **Personality**: Warm, trustworthy, rooted in Samar, friendly, and respectful.
- **Visual Style**: Kawaii anime style, glossy expressive eyes with dark red irises and sparkle highlights, pink blush marks, clean thin-to-thick dark brown outlines (`#3B2A1E`), and cel shading with soft gradient accents.

---

## 🎨 2. Official Poses & Asset Naming (`res/drawable-nodpi/`)
All Tarik mascot pose illustrations must be stored as WebP assets inside `res/drawable-nodpi/` and named strictly as follows:

| Pose Filename | Mascot Action / Interaction | Recommended Screen / Context |
|---|---|---|
| `tarik_wave.webp` | Waving hello / smiling | Login, welcome, greeting banners, onboarding |
| `tarik_read.webp` | Reading a book with glasses | Learning Hub, lessons, student portal, curriculum |
| `tarik_trophy.webp` | Cheering with golden trophy | Rewards, achievements, ceremony cards, SF generated success |
| `tarik_idea.webp` | Pensive with a glowing lightbulb | Ask TARIK AI assistant drawer, AI tips, lesson planner |
| `tarik_clipboard.webp` | Checking a wooden clipboard | Daily attendance, E-class records, DepEd SF forms hub |
| `tarik_worried.webp` | Surprised / sweaty concern | Error pages, 403, warning dialogs, action required alerts |
| `tarik_sleepy.webp` | Sleeping with ZZZ bubbles | Offline state, network sync pending, idle state |
| `tarik_love.webp` | Happy with floating heart sparkles | Enrollment approved, submission marked as done success |

---

## 📐 3. Feature Icon Badges (`res/drawable-nodpi/`)
Illustrated feature icons (used exclusively on home and dashboard cards) feature Tarik interacting with one feature object inside a 56dp circular badge with a 2dp gold ring (`#D9A834`). Naming convention: `feature_<name>.webp`.
